Documentação da API v1 · v2

Gerencie desenvolvedores, categorias, plataformas, games, usuários e perfis. Abra uma seção abaixo, clique em Testar, preencha os campos e clique em Executar. Use sempre dados fictícios nos testes.

POST · Cadastro

Envie o header X-Idempotency-Key com um valor único (ex.: um UUID).

PUT / DELETE · Login

Faça login em POST /api/auth/login e envie a chave em X-API-Key.

Versões

/v1 em todos os recursos; /v2 em categorias e games.

Limite

20 requisições por minuto por IP. Acima disso: 429 e Retry-After.
